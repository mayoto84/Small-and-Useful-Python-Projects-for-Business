Video Size Reducer

Reduce the size of videos in a folder.
View Python Source
Current implementation trims duration based on the chosen percentage. For actual file size reduction, scale resolution and set bitrate in code.

How to use

  • Click Browse Input Folder to select a directory containing videos.
  • Enter a percentage and click Reduce Videos. Output is written to resized_videos.
