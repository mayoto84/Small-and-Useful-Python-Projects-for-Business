MP4 → WAV

Extract the audio track from an MP4 video and save as WAV.
View Python Source
Requires Python with moviepy, pydub and an ffmpeg installation.

How to use

  • Launch the app, click Browse Video File, choose an MP4.
  • Click Convert! to export a WAV next to the input video.
