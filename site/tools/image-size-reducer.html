Image Size Reducer

Batch-resize images (JPG/PNG) to a given percentage.
Download Windows EXE View Python Source
The app writes resized images to a resized folder inside your chosen directory.

How to use

  • Click Browse Input Folder and choose a directory of images.
  • Enter a percentage (e.g., 50 for half size), then click Reduce Images.
